# Contribution rules

- Keep architecture and API/schema changes documented in this directory.
- Do not commit secrets, production data, generated video uploads, or build
  output.
- Preserve existing user work; do not delete or replace files without scope
  confirmation.
- Run `npm test` and `npm run build` for changes that affect application code.
- Maintain the standard API response envelope and database-backed authorization
  checks.
- Treat `docs/archive/` as historical reference, not current design guidance.

Repository/version-control workflows are owned by the project maintainer and
are intentionally not prescribed here.
